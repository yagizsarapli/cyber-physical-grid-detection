# GRIDRA Cyber-Physical Microgrid — Phase 2A

Current backbone:
- 5-bus 0.4-kV microgrid
- PV represented by a reduced-order PLL-based GFL inverter
- BESS represented by a reduced-order VSM-like GFM inverter
- finite converter current limits
- internal inverter states exposed for later anomaly detection

This file only describes the Aug-11 starting point. See `STATUS.md`
for the current state of the project (23+ phases in, cyber-vs-physical
classification, attack localization, real-time latency work).
